3. The Security ROI: Model Armor vs. Prompt Jailbreaks

While Cloud DLP and Firestore vaulting are essentially cost-free under Google Cloud's monthly tier, Google Cloud Model Armor incurs an explicit cost of $0.001 per call (1/10th of a cent).

Economic Conclusion: During malicious scanning or red-team probing, Model Armor pays for itself: blocking an injection payload at the edge costs $0.001, whereas allowing that request to execute against Gemini incurs $0.007+ in wasted output and thinking tokens, plus container memory pressure.
