Section 4

Fail-Closed Evaluation Release Gating & Exit-Code 0 Defense

In automated deployment pipelines, silent test failures represent a severe reliability risk. The ADK CLI command adk eval exits with return code 0 even when tests fail. Our production release script (evals/verify_eval_gate.sh) parses the terminal output defensively:

Defensive CI/CD Shell Parsing Protocol (cloudbuild.yaml / verify_eval_gate.sh)
# Defensive Shell Pattern: Catch Exit-Code 0 on Test Failures
OUTPUT=$(adk eval rowing_coach --config_path evals/eval_config.json 2>&1)
EXIT_CODE=$?

# Extract failure count from summary line: 'Tests failed: N'
FAILURES=$(echo "$OUTPUT" | grep -oE "Tests failed: [0-9]+" | awk '{print $3}' | tail -n 1)

if [ -z "$FAILURES" ]; then
  echo "CRITICAL: Unable to parse eval test summary line. Failing closed." >&2
  exit 1
fi

if [ "$FAILURES" -gt 0 ]; then
  echo "PIPELINE REJECTED: $FAILURES evaluation cases failed (exit code was $EXIT_CODE)." >&2
  exit 1
fi

echo "PIPELINE APPROVED: Zero test failures detected. Proceeding to production deploy."
exit 0
